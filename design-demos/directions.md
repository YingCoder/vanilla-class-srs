## 选入完整版的 3 个方向

### 方向 1 · 讲义红批手账派（Editorial Study Zine）
- **逻辑与来源**：最佳设计师（东亚）— 堀内诚一（《POPEYE》《BRUTUS》创刊艺术指导）的「图解＋手写红蓝笔批注」杂志语法；参考 `east/12-japan-magazine-dense.jpg` 样张（浅纸底占 75%，黄/红高亮占 5–10%）。
- **借的是什么**：双栏印刷网格、**手写体红笔/蓝笔批注旁注栏**与**荧光黄马克笔划重点**机制，以及「23 站路线图 + 23 天热力格」的信息组织方式。
- **不借的、自己长的**：不借骑行年报数据与纯白冷底；色彩从**学校打印单词讲义与批改红笔**采样——暖试卷纸底 `#FAF7F0`（oklch L 0.97 C 0.015）、墨水黑 `#181715`、**批改朱红 `#D63B2F`**（专用于「邪修红笔批注」与错题纠偏）、**荧光标记黄 `#F5DC4A`**（专用于高亮单词谐音切片与重点义项）。字体采用 `Noto Serif SC` 900（刊头）+ `Noto Sans SC`（正文）+ `Long Cang` / `KaiTi`（手写红笔批注）+ `JetBrains Mono`（音标）。
- **主角素材**：左右对照的「讲义活页词卡」——左面印刷正经单词与例句，右面直接贴上红笔手写「邪修暴走批注」，并用荧光笔涂黄对应的谐音字母片段。
- **骨架**：桌面端双栏学习刊页（左栏：23 天讲义目录、打卡热力阵与今日 10 词速览；右栏：精学批注词卡 / 闯关刷题 / 688 词检索切换）；手机端单栏纸面 + 底部轻量化单手切页条。
- **胆量花在哪**：把「邪修记忆」做成像班里学霸借你的那本涂满红蓝笔注脚、黄荧光划重点的实战讲义，而非冷冰冰的电子列表。
- **form 来自内容的哪里**：用户放进来的文档本身叫《23天背完中考英语高频词 **打印**》，学生最熟悉的记忆载体正是「打印纸 + 荧光笔 + 红笔口诀批注」。

### 方向 2 · 糖果卡牌特训营（Tactile Card Camp）
- **逻辑与来源**：现实参照 — 2026 App Store Cultural Impact 语言学习 App `Unedo`（实测接触表 `refs/appstore/Unedo-Spanish-Games-Stories.jpg`，高饱和多色区块 + 倾斜亮黄便签贴）× 实体集换卡牌手势；同时延续并大幅进化现有仓库 `Vanilla-card.png` 品牌形象。
- **借的是什么**：借 Unedo 接触表里**「倾斜亮黄便签提示贴 + 一屏聚焦巨型单卡 + 口语化提问句式」**机制（标题区约占首屏 18%，下方 65% 为单一主交互卡牌区）。
- **不借的、自己长的**：不借 Unedo 的深蓝与砖红配色；色彩从**现有项目 Vanilla 冰淇淋店体系**升级收紧——奶油底 `#FFF7E6`、深可可墨 `#3B281B`、**草莓暴击红 `#E24A6F`**（主按钮与邪修开关）、**薄荷绿 `#2F9E72`**（答对与已掌握）、**便签黄 `#FFD54F`**（专用于斜贴在词卡上的「邪修便利贴」）。字体采用项目自托管 `Fredoka` + `Nunito` + `Noto Sans SC`。
- **主角素材**：带实体厚度的 3D 可翻面词卡（按压下沉 `translateY(4px)` 物理反馈）+ 斜贴在卡角上的「邪修便利贴」+ `Vanilla-card.png`（base64 内嵌）作为营地教练徽章。
- **骨架**：桌面端「窄边导航 + 中央闯关大卡舞台 + 右侧实时战绩/邪修便签匣」三段式营地；手机端单手居中巨卡 + 底部拇指区双色厚底按压键（左「邪修救命」/ 右「记住了」）。
- **胆量花在哪**：每一张正经词卡右上角斜贴一张明黄色「邪修便利贴」，默认折叠一角、一点即翻开暴走口诀；所有操作键做成带底影厚度的街机按键，告别原本平坦单调的灰框列表。
- **form 来自内容的哪里**：延续已有产品「Vanilla 单词特训营」的品牌灵魂，把 23 天 688 词做成每日拆卡闯关的轻量游戏化体验。

### 方向 3 · 暗室音节黑板（Night Command Studio）
- **逻辑与来源**：秒数轮盘（`SECOND=7` → Web #8 `08-cinematic-sound-viz.jpg` & App #8 `08-command-palette.jpg`；实测近黑底占 61–83%，单色高亮仅占 8–20%）。
- **借的是什么**：借 `Sound-Viz` 的**「横贯视口的声波柱图」**和 `Command Palette` 的**「近黑分层 + 1px 发丝边界 + 键盘快捷指令槽」**机制。
- **不借的、自己长的**：不借紫蓝科技渐变和纯白/GitHub-dark `#0D1117`；色彩取自**晚自习黑板与荧光粉笔**——温润黑板炭 `#0D0C0B`、面板墨 `#161513`、粉笔灰白 `#F3EFE6`、**琥珀粉笔 `#FFB830`**（邪修爆破与音节重音高亮）、**青碧粉笔 `#38D9A9`**（拼写命中与已掌握）。字体采用 `Archivo` + `JetBrains Mono`（音标与快捷键）+ `Noto Sans SC`。
- **主角素材**：**音节声波拆解器**——把单词按音节切成等比声波柱（如 `be · cause` / `im · por · tant`），邪修谐音汉字直接挂在对应音节柱下方（`被 · 烤死` / `进口 · 蚂蚁`），点击发音波形同步律动！
- **骨架**：顶部单行极速指令栏（搜词 / `1–4` 快捷键直选 / `Space` 秒切邪修）；中央黑板主舞台（音节波柱词卡 / 沉浸四选一与键盘盲拼）；右侧或底部折叠「23 天 688 词黑板矩阵」。
- **胆量花在哪**：把原本割裂的「发音 + 拼写切分 + 邪修谐音」用一条声波图直接焊在一起，看波形就能读出谐音并记住拼写节奏。
- **form 来自内容的哪里**：初中/中职生高频使用场景之一是晚间关灯/宿舍刷词，且产品规格 §7.4 明确要求支持电脑端全键盘无鼠操作。
