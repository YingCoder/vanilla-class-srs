# 设计规格 · 单词特训营（23天中考高频词 × 邪修记忆）

## 1. 项目定位与受众
- **产品**：单词特训营（Vanilla Class SRS 前端视觉与记忆体验升级）
- **核心材料**：工作区真实词库《23天背完中考英语高频词 打印 - 副本.doc》，共 **23 天 · 688 词**（Day 1–22 每日 30 词，Day 23 为 28 词；每词含英文、音标、词性与中文释义）。
- **核心受众**：基础薄弱或容易被枯燥词表劝退的初中/中职学生（手机端通勤/课间 5–10 分钟单手刷词为主，兼容电脑机房/家用浏览器键盘操作）。
- **核心痛点与破局**：传统「单词 + 音标 + 中文」死记硬背留存率极低；加入**「邪修记忆」**（谐音暴击、拆字脑洞、拼写避坑口诀、爆笑画面联想），同时保留正经词根/例句作为「正道/邪修」双模式，让学生 3 秒记住词义并主动想点下一张。

## 2. 必须承载的真实内容与交互（三版统一）
三方向使用完全一致的真实词库数据与核心交互闭环，仅在版式结构、视觉语言与签名交互上拉开差距：

1. **23天特训地图 & 今日任务总览**
   - 展示 Day 1 – Day 23 共 688 词的推进进度（支持切换不同天预览当日真实词表）。
   - 展示今日特训状态：新词进度、复习到期词、连续学习天数（Assumed 演示状态：Day 1 进行中，已学 4/30，连胜 5 天，125 XP — 明确标注为演示态数据，实际接入后端由真实 API 驱动）。
   - L1 认识新词 / L2 英译中 / L3 中译英 / L5 拼写挑战 / Boss 关入口（遵循 `word-camp-development-v1.1.md` 闯关架构）。
2. **邪修词卡精学台（核心亮点）**
   - 单词、IPA 音标、词性、真人/Web Speech 朗读按钮、正经释义。
   - **正经 / 邪修一键切换（或翻卡双面）**：清晰区分「正道释义（词性/考试义项/例句）」与「邪修秘籍（记忆流派标签如谐音暴击/拆字脑洞/拼写避坑 + 一句话暴走口诀 + 画面拆解 + 易混避坑）」。
   - 支持切换「上一词 / 下一词 / 标记会了 / 加入错词本」。
3. **闯关测验（英译中四选一 + 拼写挑战）**
   - 从真实 23 天词库动态出题（1 个正解 + 3 个同天/同词性干扰项）。
   - 支持点击选择 & 拼写输入；**答错时自动弹出该词的「邪修救命秘籍」**，用荒诞脑洞当场把词救回来，再点下一题。
4. **全书 688 词邪修速查表**
   - 按 Day 1–23 切换、关键词即时搜索、筛选「🔥 已配邪修秘籍」词条，点任意词直接跳入词卡精学。

## 3. 输出格式与验收尺寸（三版统一）
- **载体**：响应式 Web App 高保真可交互 HTML 原型（单文件自包含，无外链图片，支持双击直接打开）。
- **交付文件**：`design-demos/dir-1.html`、`design-demos/dir-2.html`、`design-demos/dir-3.html`。
- **统一验证视口**：桌面 `1440×900` ＋ 手机 `390×844`（均通过 `polish.py shot --mobile` 逐屏截图检查 + `design_lint.py` 红黄灯检查，控制台零报错）。
- **可读性硬底线**：网页正文 ≥14px（移动端 16px），标签 ≥12px，可点击按钮高度/触控目标 ≥44px，正文对比度 ≥4.5:1。

## 4. Assumptions（因用户未额外限制而补齐的产品假设）
- 发音在原型阶段调用浏览器 `window.speechSynthesis`（英音/美音兜底），生产阶段按规格书 §7 接预生成音频与三层降级。
- 688 词全部进库可浏览、搜索与测验；首发精选 Day 1–3 全部 90 词及 Day 4–23 高频难点共 120+ 词撰写手工精编「邪修记忆」，未配词条诚实标注「待补充邪修口诀 · 可用词卡/测验」，不拿千篇一律的模板套话充数。
- 学生端全程中文为主界面，去除原有混合英文标签（如 `Tap to reveal` / `Choose a Class`）。
